# Staged fixtures

This directory contains consented, non-real media clips used for G9 and
demo evaluation runs. Every clip is **synthetic** (generated by FFmpeg from
mathematical trajectories) and contains no personal data, faces, plates,
or real incident footage.

## Fixture index

| Directory | Description | Consent |
|---|---|---|
| `g9_synthetic_v1/` | Straight-road 50 km/h stop scenario with known lane markings | Synthetic — no consent required |

## Usage

Run the G9 staged clip generator before evaluation:

```bash
python scripts/generate_g9_fixture.py
```

This creates `g9_synthetic_v1/clip.mp4` and `g9_synthetic_v1/metadata.json`
with known geometry (road width 3.5 m, known distance markers at 0 m and
17.5 m ground-plane). These values are the calibration ground truth used
to verify that Blackbox accepts or refuses metric results correctly.

## Rules

- Never commit real victim footage, real crash clips, or any media
  containing identifiable individuals.
- Never use staged fixtures as evidence in any real case review.
- Keep synthetic and real fixtures strictly separate.
